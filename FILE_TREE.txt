RAG PIPELINE
============

1. UPLOAD FLOW
   User Text → Chunking (1000 tokens) → Embeddings (1536d) → 
   Store in pgvector → Return success

2. QUERY FLOW
   Question → Embedding → Vector Search (Top-10) → 
   Rerank (Top-5) → GPT-4o → Answer + Citations

QUICK START
===========

1. Setup Database:
   - Create Supabase project
   - Run backend/schema.sql

2. Backend:
   cd backend
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   # Create .env with keys
   python setup_db.py
   uvicorn main:app --reload

3. Frontend:
   cd frontend
   npm install
   # Create .env with API URL
   npm run dev

4. Test:
   - Open http://localhost:3000
   - Upload text
   - Ask question
   - Get answer with citations!


DEPLOYMENT
==========

Backend → Render:
  - Connect GitHub repo
  - Set environment variables
  - Deploy with render.yaml

Frontend → Vercel:
  - Run: vercel
  - Set VITE_API_URL
  - Deploy: vercel --prod
