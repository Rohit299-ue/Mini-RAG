DETAILED UPLOAD FLOW
====================

User Action: Paste text and click "Upload & Process"
│
├─► Frontend (UploadPanel.jsx)
│   ├─ Validate input (not empty)
│   ├─ Show loading spinner
│   └─ POST /upload {content, title, source}
│
├─► Backend (main.py)
│   └─ /upload endpoint receives request
│
├─► Chunking (chunking.py)
│   ├─ Tokenize text with tiktoken
│   ├─ Split into 1000-token chunks
│   ├─ Add 150-token overlap
│   ├─ Preserve metadata (source, title, position)
│   └─ Return list of chunks
│
├─► Embeddings (embeddings.py)
│   ├─ Batch chunks (100 at a time)
│   ├─ Call OpenAI API (text-embedding-3-small)
│   ├─ Get 1536-dimensional vectors
│   ├─ Rate limiting (0.1s between batches)
│   └─ Return embeddings list
│
├─► Database (database.py)
│   ├─ Connect to Supabase
│   ├─ Batch insert chunks + embeddings
│   ├─ Store metadata (source, title, section, position)
│   └─ Return inserted count
│
└─► Response
    ├─ Success status
    ├─ Chunks created count
    ├─ Processing time
    └─ Frontend displays success message


DETAILED QUERY FLOW
====================

User Action: Type question and click "Ask Question"
│
├─► Frontend (QuestionPanel.jsx)
│   ├─ Validate input (not empty)
│   ├─ Show loading spinner
│   └─ POST /ask {question}
│
├─► Backend (main.py)
│   └─ /ask endpoint receives request
│
├─► Retrieval (retriever.py)
│   ├─ Generate query embedding
│   │   └─ Call OpenAI API (text-embedding-3-small)
│   │
│   ├─ Vector Search (database.py)
│   │   ├─ Connect to Supabase
│   │   ├─ Execute similarity query
│   │   │   SELECT *, 1 - (embedding <=> query) as similarity
│   │   │   ORDER BY embedding <=> query
│   │   │   LIMIT 10
│   │   └─ Return top-10 chunks with scores
│   │
│   └─ Return retrieved chunks
│
├─► Reranking (reranker.py)
│   ├─ Extract chunk texts
│   ├─ Call Cohere Rerank API
│   │   ├─ Model: rerank-english-v3.0
│   │   ├─ Query + documents
│   │   └─ Request top-5
│   ├─ Get relevance scores
│   ├─ Map back to original chunks
│   └─ Return top-5 reranked chunks
│
├─► Answer Generation (answering.py)
│   ├─ Format context
│   │   [1] chunk1 text
│   │   [2] chunk2 text
│   │   [3] chunk3 text
│   │   [4] chunk4 text
│   │   [5] chunk5 text
│   │
│   ├─ Build prompt
│   │   System: You are a helpful assistant...
│   │   Context: [formatted chunks]
│   │   Question: [user question]
│   │   Rules: Must cite sources, no external knowledge
│   │
│   ├─ Call OpenAI API (GPT-4o)
│   │   ├─ Temperature: 0.3
│   │   ├─ Max tokens: 500
│   │   └─ Get completion
│   │
│   ├─ Extract answer
│   ├─ Count tokens used
│   └─ Prepare citations
│       ├─ Citation 1: [text, source, scores]
│       ├─ Citation 2: [text, source, scores]
│       └─ ...
│
└─► Response
    ├─ Answer text (with [1], [2] citations)
    ├─ Citations array
    ├─ Processing time
    ├─ Tokens used
    └─ Frontend displays in AnswerDisplay

DATABASE SCHEMA
===============

Table: documents
┌──────────────┬──────────────┬─────────────────────────────┐
│ Column       │ Type         │ Description                 │
├──────────────┼──────────────┼─────────────────────────────┤
│ id           │ UUID         │ Primary key (auto-generated)│
│ content      │ TEXT         │ Chunk text content          │
│ embedding    │ VECTOR(1536) │ OpenAI embedding vector     │
│ source       │ TEXT         │ Source document name        │
│ title        │ TEXT         │ Document title              │
│ section      │ TEXT         │ Section name                │
│ position     │ INT          │ Chunk position in document  │
│ created_at   │ TIMESTAMP    │ Creation timestamp          │
└──────────────┴──────────────┴─────────────────────────────┘

Indexes:
- documents_embedding_idx (IVFFlat, cosine distance)
- documents_source_idx (B-tree)
- documents_title_idx (B-tree)

PERFORMANCE CHARACTERISTICS
============================

Upload Performance:
  Input: 1000 words
  ├─ Chunking: 10-50ms
  ├─ Embedding: 500-2000ms (depends on size)
  ├─ Database: 100-300ms
  └─ Total: 1-3 seconds

Query Performance:
  Input: Question
  ├─ Query embedding: 100ms
  ├─ Vector search: 50-200ms
  ├─ Reranking: 200-500ms
  ├─ LLM generation: 1-2s
  └─ Total: 2-3 seconds

Scalability:
  ├─ Documents: ~100K chunks (free tier)
  ├─ Concurrent users: ~10 (free tier)
  ├─ Queries/day: ~1000 (Cohere free tier)
  └─ Database: 500MB (Supabase free tier)
